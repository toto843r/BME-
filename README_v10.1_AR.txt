BME Portal v10.1 — تصحيح جدول الخميس B + تبليغات مؤقتة
=====================================================

هذا تحديث موحّد يحوي جميع ملفات تحديث v10 السابق مع التصحيحات الجديدة.
لا تحتاج رفع v10 القديم معه. لا ترفع ملف ZIP إلى GitHub؛ فك الضغط أولاً.

1) التعديل على الجدول (المرحلة الرابعة، شعبة B، الخميس فقط):
   • 08:30–10:30 المتحكمات الدقيقة — مختبر
   • 10:30–11:30 استراحة
   • 11:30–12:30 القياسات الطبية — نظري
   • 12:30–14:30 القياسات الطبية — مختبر
   • المعروض = 3 محاضرات (مختبر ساعتين يُحسب محاضرة واحدة).
   • يُحسب عدد الجلسات الأخرى حسب البطاقات، وليس عدد ساعات المحاضرة.

2) قسم «التبليغات» في /admin:
   • المشرف يدخل PIN كالعادة، يكتب التبليغ (حد 400 حرف) ويضغط «إرسال التبليغ».
   • يظهر تبليغ واحد في الصفحة الرئيسية فوق جدول المحاضرات، بتصميم خفيف ومتوافق مع الوضع الليلي.
   • صلاحية التبليغ 4 ساعات من وقت النشر. ينتهي تلقائياً حتى لو صفحة الطالب ما زالت مفتوحة.
   • زر «مسح التبليغ الآن» يلغيه فوراً في قاعدة البيانات؛ الزوار الجدد لا يرونه،
     والصفحات المفتوحة تتحقق دورياً كل دقيقتين كحد أقصى أو عند العودة للتبويب.
   • نشر تبليغ جديد يحل مكان التبليغ السابق.
   • التبليغ نص عادي فقط، وليس HTML، ولا يقبل الكتابة من الزائر العادي.

3) قبل النشر على موقع الطلاب (خطوة إلزامية لمرة واحدة):
   • افتح Supabase المرتبط بالموقع > SQL Editor > New Query.
   • افتح ملف supabase/portal_notices.sql من التحديث وانسخ نصه كاملاً.
   • شغّل Run. يجب أن تظهر رسالة Success. هذا ينشئ جدولاً جديداً مستقلاً؛
     لا يحذف ولا يغير items / quiz_banks / reports أو أي ملف محفوظ.
   • من الأفضل أخذ نسخة احتياطية من قاعدة البيانات قبل أي تغيير إنتاجي.

4) تحديث GitHub:
   • افتح مشروع BME- على GitHub، وافضل إجراء النشر أولاً في فرع Preview إن أمكن.
   • فك ضغط هذا ZIP وارفع محتويات app / components / lib إلى نفس مسارات المشروع.
   • يوجد أيضاً ملف SQL للتنفيذ اليدوي؛ لا حاجة لرفعه للملفات العامة.
   • إذا كنت قد رفعت v10 مسبقاً فلا مشكلة: نفس المسارات تحدّث الملفات.
   • بعد Commit انتظر أن تصبح Vercel Ready، وجرّب عرض الخميس B والتبليغات.

5) الحفاظ على الميزات:
   • يتضمن جميع تعديلات v10 السابقة: رفع المشرف المباشر، تعديل اسم الملف ونقله،
     زر الرجوع خطوة، وعداد الملفات في الامتحانات للسنسرات.
   • لا يغيّر مفاتيح Supabase/Gemini، وملفات PDF، وصور الطلاب، وبنوك الأسئلة.
   • لا مكتبات npm جديدة ولا وظائف Vercel مجدولة جديدة.

اختبارات أُجريت قبل تسليم الملف:
• فحص صياغة 43 ملف TS/TSX في نسخة المشروع: لا أخطاء صياغة.
• فحص وجود 3 جلسات الخميس B بالأوقات الصحيحة.
• فحص ربط مسارات التبليغ على الخادم وواجهتي الأدمن والصفحة الرئيسية.
• لم يُجرَ تشغيل Production Build كامل أو اختبار حقيقي على Supabase/Vercel هنا.

ملاحظة: Supabase Free قد يقيّد الطلبات عند الأحمال الكبيرة؛ التبليغات صغيرة الحجم
وتُجلب عند فتح الصفحة، مع تحديث خفيف كل دقيقتين فقط في حال وجود تبليغ نشط.
