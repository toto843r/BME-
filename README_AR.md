# BME Portal v10.5 — تحسين JavaScript الخاص بالبحث

## شنو تغيّر؟
- يظل مربع البحث ظاهراً ويعمل من أول دخول.
- مكوّن بطاقات نتائج البحث وصوره البرمجية ما يتحمّل مع الصفحة الرئيسية؛ يتحمّل فقط بعد ما المستخدم يبدأ البحث.
- نبدأ تحميل مكوّن النتائج بالتوازي مع طلب البحث حتى ما نزيد انتظار ظهور النتائج.
- لا تغيير بقارئ PDF/الصور، التبليغات، الجداول، المواد، أو قاعدة البيانات.

## التركيب
ارفع الملف `components/OmniSearch.tsx` مكان الملف نفسه في GitHub على `main`.
لا ترفع ملف ZIP نفسه. انتظر Vercel Ready.

## الاختبار
1) افتح الصفحة الرئيسية وتأكد أن مربع البحث موجود.
2) اكتب كلمتين وجرّب النتائج، افتح بطاقة، ثم اغلقها.
3) أعد فحص PageSpeed على Mobile ثلاث مرات وقارن المتوسط، لا فحصاً واحداً.

## ملاحظة مهمة
هذا تحسين حقيقي لتحميل كود نتائج البحث عند الحاجة، لكنه ليس ضماناً لعودة Performance إلى 100.
فحص Lighthouse الأخير أظهر FCP=0.8s وLCP=3.2s وTBT=50ms وCLS=0؛
العائق الأساسي للدرجة هو LCP. إذا بقي LCP مرتفعاً، افتح "LCP breakdown" وأرسل صورة له.
تحذيرات CSS الصغير 6.6KiB (~140ms) وLegacy JavaScript (~12KiB) لم نعدّلها حتى لا نؤثر على التوافق.
