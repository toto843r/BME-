BME Portal — زر «فتح بتطبيق PDF» (تحديث خفيف متوافق مع v8)

التعديل الوحيد:
components/PreviewModal.tsx

- يضيف زر «فتح بتطبيق PDF» بجانب «تحميل» و«اختبر نفسك» عندما يكون الملف PDF.
- الأجهزة التي تدعم قائمة المشاركة الأصلية (Web Share API) تعرض الخيارات المتاحة عند الضغط.
- إذا كان المتصفح لا يدعم المشاركة، يفتح ملف PDF الأصلي في تبويب منفصل بواسطة متصفح الجهاز.
- لا يحتاج حزم npm جديدة، ولا تغيير package.json أو Supabase أو Gemini أو Cron Jobs.
- لا يجلب الملف كاملاً في الذاكرة من أجل الزر: يشارك الرابط فقط؛ ولهذا لا يزيد استهلاك البيانات عند فتح الملزمة.
- فتح الملف بتطبيق قارئ محدد (مثل Books أو Acrobat) يخضع لدعم المتصفح ونظام التشغيل والتطبيق المثبت؛ لا يستطيع موقع الويب إجبار جهاز الطالب على اختيار تطبيق بعينه. قد يحتاج الطالب فتح الرابط في متصفح الجهاز واختيار «مشاركة / فتح في...» بنفسه.
- عارض PDF المتجاوب الموجود داخل الموقع يظل كما هو، وكذلك زرا التحميل والاختبار.
- لا يتضمن التحديث تغييرات v8 المتعلقة بالبحث وLCP، لكنه لا يستبدل ملفاتها ولا يلغيها. إذا لم تكن رفعت v8 بعد، ارفعه أولاً أو لاحقاً؛ الملفات لا تتعارض.

طريقة التثبيت:
1) فك ضغط ZIP (لا ترفع ZIP نفسه).
2) GitHub > BME- > main > Add file > Upload files.
3) ارفع مجلد components المحتوي على PreviewModal.tsx فقط إلى جذر المشروع.
4) تحقق من المسار النهائي components/PreviewModal.tsx، ثم Commit changes.
5) تأكد من Vercel Production Ready.
6) جرّب الزر على هاتف وعلى الحاسوب، وكذلك اختبر «تحميل» و«اختبر نفسك».

اختبارات محلية: تأكدنا من صحة مواضع التعديل وصياغة TypeScript/JSX، لكن نجاح Build الفعلي يحتاج اختبار Vercel.
