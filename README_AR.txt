BME Portal v9.1 — Universal PDF Reader

هذا التحديث يجمع عارض PDF المتطور من v9 مع ربطه على جميع أقسام الملفات (الملازم، الكوزات، المدات، الفاينلات، الملخصات، التقارير، النظري والمختبر) عند وجود ملف بصيغة PDF.

الملفات المعدلة:
  components/ResponsivePdfViewer.tsx
  components/PreviewModal.tsx

مميزات: ملاءمة تلقائية للشاشة، ضغطتين للتكبير، Pinch zoom، التمرير على الملفات المكبرة، الانتقال بين الصفحات، التحميل التدريجي للصفحات، دون مكتبات جديدة أو تغييرات على Supabase.

ملاحظة: لا يحوّل ملفات Word/PowerPoint إلى PDF؛ تبقى بمعاينتها الأصلية. ولا يفعّل توليد أسئلة AI للأقسام الأخرى، بل يغيّر قارئ PDF فقط. زر "اختبر نفسك" يبقى مخصصاً لملازم المحاضرات.

التركيب:
1. فك الضغط.
2. ارفع مجلد components إلى جذر مستودع GitHub الأساسي بحيث يستبدل الملفين بالمسارين أعلاه.
3. لا ترفع ملف ZIP نفسه إلى GitHub.
4. يفضّل فحص Preview أو Build قبل تحديث Production. بعد النشر اختبر PDF من قسم الملخصات والمدات والمختبر.

لا حاجة لتعديل package.json أو مفاتيح البيئة أو تشغيل SQL.
