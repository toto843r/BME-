BME Portal — تحديث موحّد v8 (البحث + ظهور المحاضرة القادمة)

هذا تحديث جزئي لنفس مشروعك الموجود على GitHub، وليس مشروعاً جديداً.
يحتوي على أربعة ملفات برمجية فقط:

1) components/OmniSearch.tsx       تحديث البحث
2) app/api/search/route.ts        إضافة مسار البحث من جهة الخادم
3) components/NextClass.tsx        عرض المحاضرة القادمة مباشرة من HTML
4) app/page.tsx                   تمرير وقت بغداد والشعبة إلى المكون

التحسين الأول: البحث
- لم يعد الهاتف يحمّل فهرس آلاف الملفات عند بدء الكتابة.
- الخادم يبحث عن النتائج ويرسل حتى 40 نتيجة مطابقة فقط.
- ينتظر 320 مللي ثانية بعد الكتابة حتى يقلل الطلبات.
- يحتفظ ببحث الخادم مؤقتاً لدقيقتين، وبآخر عمليات البحث مؤقتاً لدقيقة على الجهاز.
- يدعم أسماء المواد والأساتذة والوسوم والنظري والمختبر مثل السابق.
- البحث يحتاج إنترنت، ولا يغيّر وضع PWA دون اتصال.

التحسين الثاني: المحاضرة القادمة / LCP
- بدل أن تكون بطاقة الجدول فارغة حتى تنفيذ useEffect، يرسم الخادم المحاضرة القادمة ضمن أول HTML.
- يستخدم توقيت بغداد لحساب المحاضرات حتى إذا كان الطالب مسافراً.
- يحتفظ باختيار الشعبة A/B محلياً، ويضيف Cookie بسيطاً لتذكر الشعبة أثناء العرض الأول.
- يستمر تحديث العدّاد كل 30 ثانية عندما تكون الصفحة نشطة.
- الصفحة الرئيسية أصبحت ديناميكية لتزويدها بوقت حديث من الخادم؛ قد يزيد هذا زمن استجابة الخادم في بعض الحالات، لذا يجب إعادة قياس PageSpeed بعد النشر للتأكد من صافي التحسن.

طريقة التثبيت (بالكمبيوتر):
1. فك ضغط ZIP، لا ترفع ملف ZIP نفسه.
2. افتح GitHub → مشروع BME- → فرع main.
3. Add file → Upload files.
4. ارفع مجلدي app و components بمساراتهما الأصلية.
5. تأكد من استبدال الثلاثة الملفات الموجودة وإضافة app/api/search/route.ts (إن لم يكن موجوداً).
6. اضغط Commit changes وانتظر Vercel Production Ready.
7. جرّب البحث، تبديل الشعبة، ورابط المحاضرة القادمة؛ ثم أعد قياس Mobile PageSpeed.

لا تحتاج إلى مكتبة جديدة، ولا متغيرات بيئة جديدة، ولا SQL، ولا أي تغيير في Gemini أو Supabase أو ملفات PDF أو الاختبارات.

الفحوص المحلية: تدقيق صياغة TypeScript/TSX ومسارات الملفات واختبارات منطق الساعة.
لم يتم إجراء Next.js Production Build كامل هنا بسبب عدم توفر حزم npm، ولذلك يجب مراقبة Vercel بعد رفع التحديث.
