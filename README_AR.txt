BME Portal v9.2 — تحسين عارض الصور بدون تغيير عارض PDF
====================================================

الملفات داخل هذا التحديث:
  components/ResponsiveImageViewer.tsx   (ملف جديد)
  components/PreviewModal.tsx            (استبدال ملف موجود)

المزايا:
- عرض الصور JPG / JPEG / PNG / WebP / GIF / BMP / AVIF ضمن الشاشة.
- تكبير بالضغط مرتين، أو بإصبعين (Pinch) على الهاتف.
- تحريك الصورة المكبرة بالإصبع أو بالماوس، وإرجاعها للحجم الطبيعي.
- أزرار تكبير وتصغير وإعادة ملاءمة الصورة، حتى 400%.
- بقاء التنقل بين الصور أو الملفات المتعددة بواسطة الأزرار والتبويبات الأصلية.
- اكتشاف صيغ الصور من المسار أو الاسم للملفات القديمة ذات التصنيف غير الصحيح.
- عدم تنزيل أي صورة إضافية إلا عند فتحها، وعدم إضافة مكتبات جديدة.

لا يغير:
- عارض PDF v9.1 أو الملفات الفعلية أو Supabase أو اختبارات Gemini.
- زر تحميل الملف أو العرض المعتاد لملفات أخرى.

كيفية التثبيت:
1) نزّل ZIP وفك ضغطه (Extract All).
2) افتح GitHub > مشروع BME Portal > فرع main.
3) Add file > Upload files، وارفع مجلد components الموجود داخل التحديث.
4) تأكد أن المسارين هما:
   components/ResponsiveImageViewer.tsx
   components/PreviewModal.tsx
5) اضغط Commit changes وانتظر أن يصبح نشر Vercel Ready.
6) افتح صورة من الملخصات أو المختبر أو أي قسم وجرب الضغط مرتين والتكبير بإصبعين.

تنبيه:
هذه الميزة للملفات التي هي صور مستقلة (JPG/PNG وأشباهها)، أما PDF
المكوّن من صفحات ممسوحة ضوئياً فيستمر استخدام قارئ PDF الحالي.
جودة الصورة المكبرة لا يمكن أن تتجاوز دقة الملف الأصلي.

الفحوص المتاحة هنا: نجاح تحليل صياغة الملفين TypeScript/TSX واختبارات منطق التكبير.
لم يُنفذ Production Build كامل، لذا يجب التحقق من نشر Vercel وعمل اللمس على الهاتف.
