BME Portal v10.4 — Image/Text Fix + Dynamics Sources Section
=============================================================

هذا التحديث يدمج إصلاح v10.3 (إظهار نص الكوز تحت الصورة مع الحفاظ على الزوم)
مع تعديل قسم ديناميكا جسم الإنسان فقط:

ترتيب الأقسام: الملازم -> المصادر -> الكوزات -> المدات -> الشروحات.
- إخفاء تبويبي الفاينلات والملخصات بالديناميكا فقط؛ لا يتم حذف الملفات القديمة من Supabase.
- إضافة قسم مصادر حقيقي لقبول ملفات PDF والصور وWord وPowerPoint ونقل الملفات إليه من لوحة المشرف.
- تبقى بقية المواد وأزرارها وأقسامها كما هي.
- لا تتغير ملفات PWA أو عارض PDF أو نظام الأسئلة.

مهم جداً — نفذ الخطوتين بالترتيب:

1) قبل رفع ملفات الموقع:
   Supabase > مشروع BME4 > SQL Editor > New Query
   افتح الملف supabase/dynamics_sources_v10_4.sql وانسخ محتواه إلى محرر SQL ثم Run.
   يستبدل قيد الفئات فقط ليسمح بقسم sources ويمنعه خارج الديناميكا؛ لا يحذف سجلات.
   لو ظهر خطأ لا ترفع كود الموقع قبل حلّه.

2) GitHub: على الفرع main بمستودع المشروع الحالي:
   فك ضغط ZIP ولا ترفع ZIP نفسه.
   ارفع محتويات مجلدات app وcomponents وlib وsupabase إلى مساراتها الأصلية.
   ملف supabase/schema.sql لتجهيز نسخة جديدة مستقبلاً فقط، لا تشغّل schema.sql على القاعدة الحالية.
   بعد Commit انتظر Vercel حتى Ready.
