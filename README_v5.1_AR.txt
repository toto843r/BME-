BME Portal — تحديث v5.1 (تصحيح اسم امتحانات+)

هذا الملف يحتوي على كل تعديلات v5 المُراجَع السابقة، مع إصلاح مظهر اسم تبويب امتحانات+ في مادة المتحسسات الحيوية (Sensors).

الإصلاح:
- يظهر اسم التبويب «امتحانات+» دون إلحاق الرقم 0 أو عدد آخر به.
- بقية التبويبات تظل تعرض عدد الملفات كالعادة.
- لا تتغير ملفات الامتحانات أو بيانات Supabase، ولا يتأثر محتوى Quizzes وMidterms للمواد الأخرى.

طريقة الرفع:
1. لا ترفع ملف v5 القديم أو الملف المُراجَع السابق معه؛ هذا التحديث يحويهما.
2. فك ضغط ZIP.
3. افتح مستودع GitHub الأساسي، واختر main.
4. اختر Add file ثم Upload files، وارفع محتويات ZIP (وليس ZIP نفسه).
5. تحقق من أن المسارات مطابقة للموجودة في المشروع؛ ثم Commit changes.
6. تابع Vercel → Deployments حتى تصير الحالة Ready وتأكد من ظهور تبويب «امتحانات+».

تنبيه:
نجاح النشر/البناء يجب التحقق منه على Vercel؛ لا يحتاج هذا التصحيح تغيير Supabase أو Gemini.
إذا ظل رقم 0 ظاهراً، أعد تحميل الصفحة تحديثاً كاملاً للتأكد من عدم ظهور نسخة PWA المخزّنة.
