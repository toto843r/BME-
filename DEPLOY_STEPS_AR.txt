تحديث BME Portal — التوليد التلقائي دون ضغط زر أو موافقة
================================================
هذه الحزمة تحديث جزئي للكود الذي رفعته مسبقاً على GitHub، وليست مشروعاً جديداً.

على GitHub:
1) افتح نفس المستودع وعلى الفرع التجريبي bme-pwa_test (أو الاسم الدقيق عندك).
2) فك الضغط وارفع الملفات الداخلية *كما هي* عبر Add file → Upload files، ثم Commit changes.
3) انتظر في Vercel حتى يصبح آخر Preview = Ready.
4) في صفحة Upload ارفع PDF تجريبياً واحداً ضمن قسم المحاضرات؛ الأسئلة تبدأ بالتجهيز دون انتظار موافقة الأدمن.
5) افحص Supabase → Table Editor → quiz_banks ولا تحذف شيئاً.

لا تعيد SQL quiz_banks.sql، فهو مطبق عندك. ولا تحتاج تغيير GEMINI_API_KEY في Preview.

بعد التأكد من نجاح الاختبار فقط، نتجه لإعداد Production:
- مفتاح Gemini API ضمن Free Tier بدون Billing.
- متغير CRON_SECRET آمن في Vercel Production لتشغيل فحص الاستكمال اليومي.
- انتبه: فحص Vercel Cron لا يعمل في Preview، ولا نضمن إتمام توليد طويل فوراً أو عدداً غير محدود مجاناً.

التوليد منفصل عن الموافقة على نشر المحتوى. حذف موافقة نشر الطلاب غير مطلوب ولم يتم.
